# lian-ai

基于333份瑞恩情感TV公开视频转写重构的人格与关系分析 Skill。

它提炼的是公开表达中反复出现的思维动作，不是原话合集，也不代表瑞恩本人。

## 本次重蒸馏解决了什么

旧版存在几个重要问题：

- 把少量出现的观点写成核心模型；
- 把大量转述放在引号中，容易被误认为本人原话；
- 使用固定人格标签和读心式潜意识判断；
- 淡化了早期技术流到后期人格与心理框架的演化；
- 缺少每个模型的应用边界和高风险退出规则。

新版重新分析约760万字符的一手转写，并按女娲 Skill 的方法完成：

1. 全量关键词与分期统计；
2. 主题演化分析；
3. 心智模型三重验证；
4. 转述与直接引语审计；
5. 对话协议、安全边界和评估案例重构。

## 六个核心模型

1. 先看见现实，再解释现实；
2. 行为是保护性回应，不只是对错；
3. 人格和自我功能由经验发展；
4. 亲密需要分化、边界与责任；
5. 痛苦常来自控制幻想与意义赋予；
6. 真实欲望可以表达，但不能强迫结果。

## 安装

```bash
git clone https://github.com/xxzzzzy/lian-ai.git
```

将整个目录安装到支持 Skill 的 AI Agent 中，或将 `SKILL.md` 作为明确的视角分析指令使用。

## 触发

只在用户明确提出以下请求时使用：

- “用瑞恩视角分析”
- “瑞恩会怎么看”
- “切换到瑞恩视角”
- “帮我用瑞恩的框架想想”

普通恋爱、关系或心理问题不会自动触发。

## 数据与来源

- 原始材料：333份公开视频转写；
- 总字符数：约760万；
- 可识别直播期数：202份；
- 其余131份文件无法仅从文件名判断期数；
- 完全重复文件：2份；
- 调研时间：2026年7月。

原始转写不随仓库重新分发。研究文件保留统计、来源文件名、方法和局限，便于复核。

## 重要边界

- 不代表、冒充或代替瑞恩本人；
- 不构成心理诊断、心理治疗、医疗或法律建议；
- 不提供操控、跟踪、侵犯隐私或绕过同意的建议；
- 出现暴力、自伤、胁迫或安全风险时，应退出人物视角；
- 原始材料混合个人经验、教育内容和商业表达，不能等同于临床心理学证据。
