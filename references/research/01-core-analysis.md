## 主题演化

按可识别期数分段后，主题变化明显：

| 阶段 | 主要特点 |
| --- | --- |
| 约100-149期 | `game`、框架、展示面、吸引和结果导向占主导 |
| 约150-199期 | 技术语言仍多，但开始强调责任、经验和真实表达 |
| 约200-249期 | 心理学、人格、自恋、投射和防御机制快速增加 |
| 约250-324期 | 人格发展、边界、分离、意义和自然表达成为稳定主题 |
| 约325-400期 | 防御机制、自我功能、现实检验和人格整合最集中 |

因此，瑞恩的公开框架不是静态体系，而是从技术和结果语言逐步迁移到心理动力学、人格发展和现实接触。新版 Skill 以较成熟的中后期框架为主，但必须保留这条演化线，不能把后期立场倒写成始终如此。

## 对旧版六模型的审计

| 旧模型 | 判断 | 处理 |
| --- | --- | --- |
| 重新定义问题 | 对话模式成立，但不是独立世界观 | 降为回答协议 |
| 所有行为背后都有机制 | 覆盖广，生成力强 | 保留并改写为“行为是保护性回应” |
| 先做完整的人 | 方向成立，但表述过于口号化 | 改写为“人格靠经验发展” |
| 渣男感的本质 | 带有阶段性行业语言，容易误导 | 删除为核心模型 |
| 看行为不看语言 | 可用，但覆盖不足且过度简化 | 降为现实检验启发式 |
| 允许一切发生 | 精确短语覆盖很低 | 并入“可控、不可控与意义赋予” |

## 新版核心候选

通过跨话题复现、对新问题有生成力、并具有一定排他性后，保留六个候选：

1. **先看见现实，再解释现实**
2. **行为是保护性回应，不只是对错**
3. **人格和自我功能由经验发展**
4. **亲密需要分化、边界与责任**
5. **痛苦常来自控制幻想与意义赋予**
6. **真实欲望可以表达，但不能强迫结果**

这些模型的证据、应用和局限见后续研究文件。
